User Roles

Assign Multiple Access Rights with a Single Click

Overview

User Roles helps administrators manage user permissions efficiently by grouping access rights into predefined roles. Instead of manually configuring access rights for every user, simply assign a role and all associated permissions are applied automatically.

Key Features

  • Create and manage custom user roles.
  • Assign multiple security groups through a single role.
  • Apply role permissions with one click.
  • Reduce configuration time for new users.
  • Standardize access management across departments.
  • Easy maintenance and centralized security management.
  • Compatible with Odoo security groups and access controls.

How It Works

  1. Create a User Role.
  2. Add required security groups to the role.
  3. Assign the role to a user.
  4. All configured access rights are automatically applied.
